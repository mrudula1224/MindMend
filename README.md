# 🧠 Mental Health Support Agent

A simple and calming web-based chatbot designed to provide mental wellness support through positive affirmations and guided meditations.

## 💡 Features

- 🌸 Clean and soothing UI
- ✨ Positive affirmations at the click of a button
- 🧘 Guided meditation prompts
- 💬 Text input for personalized support

## 🚀 Getting Started

This project runs on [Streamlit](https://streamlit.io/). To run it locally:

### Prerequisites

- Python 3.7+
- `pip`
